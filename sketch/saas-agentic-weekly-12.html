26.2 Release Hot off the press Jul 28, 2026

What's New in 26.2 -- The Agentic AI Release

The BMC Helix 26.2 release for ServiceOps delivers AI-driven automation across four domains. Key themes: autonomous triage, CMDB quality automation, multi-platform log RCA, and first steps toward open agent interop. [6][7]

AIOps: Root Cause Finder now orchestrates diagnostic AI agents (logs, metrics, change agents) across Elastic, Splunk, and Helix Log Analytics. Composite alarm thresholds reduce false positives via multi-metric correlation. Context-aware Ask HelixGPT answers based on the page being viewed. [6]

Discovery: IPsec logical network relationships discovered via SNMP/REST API. Containerized software relationships visualized at pod/deployment/container levels. End-user device ingestion from Microsoft Intune into CMDB. [6]

Automation & Compliance: Patch Orchestrator automates change approvals, pre-checks, patch analysis, remediation, and post-patching. Vulnerability Resolver now auto-generates Ansible scripts with human review before execution. Native Microsoft Defender vulnerability scanner support. [6]

Service Management: Ticket Resolver (auto triage), CMDB Governor (data quality), enhanced Employee Navigator (Teams workflows, image analysis, submit-on-behalf-of), enhanced Catalog Curator (conditional questions, one-click confirmations), enhanced Ops Swarmer (parallel RCA). [6]

Agent Studio: New modular knowledge tools (Retriever, Grader, Filter). Cloning of agent skills for reuse. Controlled availability A2A (Agent2Agent) protocol for third-party agent integration. NeMo Guardrails and policy-driven enforcement. Token consumption dashboards. [6]

MSP Features Multi-Tenancy Since 25.1 Release

Multi-Tenancy Dashboards -- BMC Has MSP Infrastructure, Not MSP Go-To-Market

BMC Helix has supported multi-tenancy since the 25.1 release, providing dedicated dashboards for MSPs managing multiple client instances. This is an important distinction -- unlike ServiceNow or Atlassian JSM, BMC has explicitly built tenant-isolation features for MSPs. [8]

  • Multi-tenant dashboards: Configurable per-tenant panels for events, alarms, KPIs across hundreds of client instances -- no separate login needed [8]
  • Tenant types: Master tenant (provider), default subtenant (first client), and per-client tenants. Full data isolation per tenant [8]
  • Compliance support: DORA (Digital Operational Resilience Act), FFIEC, data security, data residency [8]
  • Discovery automation: Agentless discovery across tenant environments, automated CMDB population [8]

But the MSP story stops there: No PSA integration (no ConnectWise, Autotask, HaloPSA). No client billing or cost-attribution model. No consumption-based AI pricing. Multi-tenancy is for enterprise-style tenant separation, not MSP client reselling. At $115/user/mo, reselling to SMB clients would destroy margins. [9]

Lifecycle stages:

  • 1. Intake: Employee submits via Teams, email, portal, API, or mobile app. Employee Navigator captures conversational context and images. Service Collaborator provides chat-based triage. [6][10]
  • 2. Classification (Autonomous): Ticket Resolver predicts urgency and impact. Service Collaborator searches knowledge base, past tickets, and CMDB context. Multiple agents can be invoked in parallel. [6]
  • 3. Resolution or Escalation: For known/policy-covered issues, Ticket Resolver auto-resolves with proactive follow-up. For unknown/complex issues: Ops Swarmer creates Teams war room, Root Cause Finder runs deep RCA across log platforms, Best Action Planner recommends remediation. [6][7]
  • 4. Human-in-the-Loop: Ops Swarmer recommends participants based on past response patterns. Vulnerability Resolver auto-generates scripts but requires human review before execution. CMDB Governor auto-corrects but flags changes. [6][10]
  • 5. Post-Mortem: Post Mortem Analyzer generates incident review. Knowledge Curator creates KB articles. CMDB updated with new relationships. [3][6]
  • 6. Continuous Feedback: Every agent action, human override, and resolution feeds back into the HelixGPT model. Agent performance dashboards track value realization metrics. [6]

Risk Signal Forrester Dec 2025

Forrester Caution: Governance, Economics, and Competition

In December 2025, Forrester analyst Julie Mohr published a cautious assessment of BMC's agentic AI vision. While acknowledging the potential, she flagged four headwinds: [4]

  • Governance gap: Autonomous agents require "robust governance, clear accountability, and deep integration with existing ITSM/IOM processes." Without these, "organizations risk creating fragmented automation that adds complexity" [4]
  • ROI uncertainty: Translating avoided outages or reduced MTTR into hard financial savings is "notoriously tricky." CFO dashboards help but aren't enough for procurement [4]
  • Competitive pressure: ServiceNow and Atlassian are investing heavily with "larger ecosystems and stronger brand recognition." BMC's multi-cloud openness is a differentiator but may not overcome vendor inertia [4]
  • Organizational readiness: Moving from manual workflows to autonomous agents requires "trust, training, and a willingness to rethink processes" -- a multiyear journey for most enterprises [4]
