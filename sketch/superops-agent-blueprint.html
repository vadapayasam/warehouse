Batch 3

How to Build Agents - Architecture Patterns

Across all 12 vendors, 5 distinct agent architecture patterns emerged. Here's how they work and what SuperOps should build.

The 5 Agent Patterns

1

Copilot / Assist Pattern

AI suggests, human decides. Best for: ticket summarization, script generation, KB search. Lowest risk, fastest to ship. Used by: Atera, ServiceNow Now Assist, ConnectWise Copilot.

2

Conversational Agent Pattern

Natural language interface over existing workflows. Best for: ticket deflection, KB Q&A, patch intelligence. Used by: Freshworks Freddy, SuperOps Ask Monica, BMC Helix Service Collaborator.

3

Autonomous Resolution Pattern

Agent owns the full resolution lifecycle. Best for: common ticket types, password resets, software installs. Used by: Freshworks Freddy (80% auto-resolve), BMC Ticket Resolver.

4

Agent Builder / Marketplace Pattern

Let users and partners create custom agents. Best for: ecosystem play, differentiated use cases. Used by: BMC Helix Agent Builder, Atomicwork, SuperOps Marketplace + AWS.

5

Multi-Agent Orchestration Pattern

Coordinated fleet of specialized agents. Best for: complex cross-domain workflows. Used by: ServiceNow (300+ skills, LEAP), BMC Helix (5-agent fleet), ConnectWise (9 agents).

Batch 3 · Implementation

What to Build - Agent Implementation Plan

Prioritized by competitive gap analysis. SuperOps's per-endpoint pricing is a structural advantage - agents should reinforce it.

Priority 1

Auto-Ticket Resolution Agent

Freshworks Freddy resolves 80% autonomously. Atera is assist-only. SuperOps has the MSP trust + per-device pricing to own this gap.

Autonomous High Impact 
Goal: Resolve common tickets without human touch
Trigger: Email/Portal ticket creation
Flow:
  1. Intent classification (password reset, software request, info inquiry)
  2. KB matching + solution retrieval
  3. Confidence check (>85% auto-resolve, else human queue)
  4. Resolution + notification + feedback loop
Metrics: Resolution rate, handle time reduction, user satisfaction
Priority 2

AI Patch Manager (Enhance Monica)

SuperOps already has AI Patch Manager in Level 3. Extend it: auto-discover, analyze severity, deploy with rollback, report compliance.

Existing Deepen 
Capabilities to add:
  - Vulnerability severity ranking (CVSS + community sentiment)
  - Test group deployment before broad rollout
  - Auto-rollback on failure detection
  - Compliance report generation
  - Patch window scheduling per client policy
Differentiator: Multi-tenant patch orchestration
Priority 3

Intelligent Dispatcher

BMC Ops Swarmer recommends team members. ServiceNow routes by skill. SuperOps should auto-assign tickets based on technician skill, load, and SLA risk.

Workforce AI Routing 
Inputs: Ticket type, client, urgency, technician skills, current load
Output: Ranked assignment recommendation + SLA prediction
Pattern: Collaborative filtering + rules override
Integration: PSA dispatch queue, mobile notification
Priority 4

Custom Agent Builder

BMC Helix and Atomicwork have no-code agent builders. SuperOps Marketplace needs this: let MSPs build custom agents per client workflow.

Marketplace Platform Play 
Builder Spec:
  - Trigger selection (ticket created, alert fired, schedule)
  - Action sequence (KB lookup, script run, ticket update, notify)
  - Condition logic (IF/AND/OR thresholds)
  - Test mode with dry-run
  - Publish to Marketplace (private or public)
Monetization: Free builder, paid publishing, rev share
