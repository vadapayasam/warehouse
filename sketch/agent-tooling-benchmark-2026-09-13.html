Warehouse / agent operations

What actually gets faster?

A small benchmark of the tools installed for agents working on this HTML archive.

Design read: technical field report for an agent-operated HTML archive, dark editorial, low-motion, data-led.
Keep the tools. Do not expect magic.

On this repo, the absolute gains are measured in milliseconds. The bigger win is that agents get sharper commands for search, repeatable project setup, safe edits, and browser proof.

The useful loop

INPUT

Issue

Give the agent a bounded task and acceptance criteria.

ISOLATE

Worktree

Let parallel tasks edit separate copies of the repo.

PROVE

Test

Run just, lint, build, and Playwright checks.

HANDOFF

Publish

Review the diff, then open a PR or publish the HTML artifact.

Verdict for this repo

Keep: rg, ast-grep, mise, just, Playwright, and Git worktrees.

Optional: fd. Native find is faster on this small archive.

Later: benchmark on a larger product repo. That is where search and setup differences become meaningful.

Next test

Run the same commands against a larger JavaScript or TypeScript codebase with cold and warm caches. Add agent task completion time, test pass rate, and screenshot review time.
